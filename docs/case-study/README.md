# Case-study index

This case study is designed for selective reading rather than a compulsory front-to-back pass.

## Shortest useful paths

- **Hiring manager or recruiter — 5 minutes:** scan [At a glance](../../README.md#at-a-glance), the [three delivery proof stories](../../README.md#three-delivered-proof-stories), [evidence boundaries](../../README.md#evidence-boundaries) and the [capability matrix](../../README.md#capability-to-evidence-matrix); open the [delivery timeline](delivery-timeline.md) only for the deeper ownership story.
- **Client or event producer:** read the [visitor journey](03-visitor-journey.md), [The Ground hand-off](04-the-ground-event-interface.md), [Queue-to-Sheets workflow](05-queue-to-sheets-interface.md) and [production economics](07-production-economics-and-observability.md).
- **Engineer or technical reviewer:** begin with the [system overview](../diagrams/system-overview.svg), then use the [decision records](../decisions/) and [evidence index](10-evidence-index.md) to move from each claim to code and tests.
- **AI delivery reviewer:** read the [evidence-first Agent workflow](02-evidence-first-agent-workflow.md), the [reconstructed MVP brief](../agent-workflow/reconstructed-mvp-brief.md) and the [delivery timeline](delivery-timeline.md) together; none is intended to imply one-prompt production delivery.
