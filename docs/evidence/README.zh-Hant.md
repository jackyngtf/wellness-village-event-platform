# 本案例研究使用的項目紀錄

[English](README.md) · [**繁體中文**](README.zh-Hant.md)

可執行 demo 可以展示網站目前的行為，但不能重現當時交付日期、活動流量、帳戶計費或 Search Console 報告。本目錄保留經整理的項目紀錄，同時移除客戶及帳戶資料。

| 紀錄 | 涵蓋內容 | 不包括的資料 |
| --- | --- | --- |
| [交付時間線](delivery-timeline/README.zh-Hant.md) | 由首個可審閱 MVP 到正式上線、活動運作及其後 metrics review 的里程碑 | 私人訊息、身份、引文、附件，以及沒有數據支持的 productivity 或 business-impact claim |
| [正式環境指標](production-metrics/README.zh-Hant.md) | 活動時段流量、runtime 用量、共享帳戶計費位置及首年網域直接成本 | identifiers、個人資料、原始 submissions、付款資料，以及來源不能支持的項目成本分攤 |
| [搜尋與索引](search-discoverability/README.zh-Hant.md) | 正式 `robots.txt`、雙語 sitemap 行為，以及經整理及核實的 Search Console 結果 | 帳戶身份、screenshots、permission listings 及低流量 query 原始資料 |

每份紀錄都會寫出擷取日期、來源及解讀限制。這些檔案不是 credentials、operational backup，亦不能取代私人項目紀錄。
