# Public evidence directory

This directory retains sanitised, inspectable records for claims that cannot be reproduced solely from the runnable reference application.

| Evidence set | What it supports | What it excludes |
| --- | --- | --- |
| [Production metrics](production-metrics/) | Bounded event-window traffic, runtime usage, shared-account billing position and the direct first-year domain cost | Identifiers, personal data, raw submissions, payment details and project attribution that the source cannot support |
| [Search discoverability](search-discoverability/) | Captured production `robots.txt`, bilingual sitemap behaviour and sanitised verified Search Console outcomes | Account identity, screenshots, permission listings and raw low-volume query data |

Every retained record states its capture date, source scope and interpretation limits. These files are evidence for a portfolio claim, not credentials, operational backups or a substitute for the private production record.
